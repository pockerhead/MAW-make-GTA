Эксперимент: можно ли за один присест, без человека-программиста, собрать играбельный прототип
GTA-подобной игры от третьего лица силами мультиагентного пайплайна [MAW](https://github.com/pockerhead/maw).

Человек здесь только ставит задачу и смотрит на результат. Диздок, нарезку на задачи, код, ревью и QA
делают агенты. Оркестратор (Claude Code) сам решает все блокирующие вопросы и сам принимает диздок.

## Как это началось

Всё, что дал человек, — три сообщения. Дальше работали агенты.

**1. Старт** — после установки MAW в пустую папку:

> Этот репо — экспериментальный проект: хочу, чтобы агенты на MAW сделали мне игру по типу GTA от третьего
> лица. Движок — Bevy. Любые наработки можно брать из моего прошлого проекта на Bevy — там куча доков по Bevy
> и крейтов, из которых можно взять архитектуру и прочее.
>
> От тебя сейчас требуется создать AGENTS.md и CLAUDE.md по типу того проекта, а ещё наполнить MAW context
> начальными данными. Потом запустить первую deep-research задачу, в которой уточнить у меня требования к игре:
> какие механики и возможности она должна давать, что по UI/UX, открытый мир или нет, и так далее — то есть
> собрать, по сути, диздок и распределить его по задачам. Но прямо сейчас тебе надо наполнить MAW context —
> архитектурно и процессно.

**2. Полная автономия** — когда контекст был готов:

> Окей, смотри: дальше работаешь полностью автономно до хорошего такого играбельного прототипа — открытый
> процедурный разнообразный мир, физика, стрельба, ближний бой, третье лицо, полиция, бандиты, мирные жители,
> здания, парки и так далее, всё примерно как в GTA… Это всё должно быть формализовано в диздоке и разрезано
> на задачи. Все PCTX proposals разбираешь и нарезаешь сам после каждой задачи — здесь автономия полная.
> Эксперимент именно в том, чтобы игра, начиная с диздока и до конца, была сделана за один присест.

**3. Уточнение правил** — через пару минут:

> Без инлайна, без блоков. Точнее, каждый блок решаешь сам.

Всё остальное в истории репо — работа агентов. Человек по ходу дела только правил процесс (что игнорить в git,
как считать стоимость) и один раз отменил фичу, которая съела пять часов, — см. `docs/narrative-graph.md`.

## Что строим

- Rust + [Bevy](https://bevy.org) 0.19, весь движок: ECS, рендер, звук, ввод
- открытый процедурный город: улицы, кварталы, здания, парки
- камера от третьего лица, физика, стрельба, ближний бой
- мирные жители, банды, полиция с уровнем розыска

Утверждённый диздок: [`docs/design/GDD.md`](docs/design/GDD.md) — 16 вертикальных слайсов, от каркаса с камерой
до трафика и полицейских погонь. Стек: Bevy 0.19.1, avian3d (физика), bevy-tnua (контроллер), bevy_enhanced_input,
Kenney CC0 ассеты, Bevy Remote Protocol для автоматического QA запущенного билда.

## Как это работает

Каждая задача проходит adversarial-пайплайн MAW:

```
clarifier → premise-challenge → planner → plan-review ×2 → implementer → code-review → fixer → QA
```

Стадии делят две модели: Claude (Opus) и OpenAI Codex (gpt-6-sol; первые три codex-стадии — TASK-001 premise и plan-review-1, TASK-002 premise — по ошибке оркестратора прошли на gpt-5.6-sol, это видно в их `metrics.md`). Ревьюер всегда работает на другой
модели, чем автор, чтобы у них не совпадали слепые пятна. После каждой стадии состояние папки
коммитится и пушится сюда, поэтому история репо и есть лог работы агентов.

- `maw/tasks/{pending,in_progress,done,blocked}/` — доска задач. В папке задачи лежат все артефакты стадий:
  `PLAN*.md`, `IMPL_SUMMARY.md`, `IMPL_REVIEW.md`, `QA_REPORT.md`, `metrics.md` (токены и время по каждому агенту)
- `maw/project-context/` — знание о проекте, которое инжектится агентам: инварианты, доменные модули,
  инструкции для каждой стадии
- `maw/ROADMAP.md` — граф зависимостей задач (генерируется)
- `docs/narrative-graph.md` — куда движется проект и почему
- `AGENTS.md` / `CLAUDE.md` — инструкции для главной сессии

Сам MAW (скиллы и агенты в `.claude/` и `.agents/`) в репо не лежит. После клона:
`curl -fsSL https://raw.githubusercontent.com/pockerhead/maw/main/install.sh | sh`

## Сколько это стоит

Токены посчитаны по фактическим транскриптам всех агентов (Claude — сабагенты и сессия-оркестратор,
Codex — события `turn.completed`) и переведены в цены публичных API. Реально работа идёт по подпискам
(Claude Max, ChatGPT), так что это оценка "сколько стоило бы через API", а не счёт.

| **Итого** | | | **$348–401** |

Цены за 1M токенов: Opus 5.5 — $4 вход / $20 выход / $0.20 чтение кэша / $5–8 запись в кэш (TTL 5 мин или 1 ч);
gpt-6-sol — $2 / $10 / $0.20 кэш; gpt-5.6-sol — $4 / $20 / $0.40 кэш. Вилка — из-за неизвестного TTL записи в кэш.
Почти весь объём — чтение кэша: каждый ход агент перечитывает свой контекст.

## Запуск

Нужен Rust 1.95 (stable) и Python 3. Из корня репо сначала скачать CC0-ассеты по манифесту
(в git их нет; в релизах они лежат в zip):

```
python tools/fetch_assets.py
```

Потом:

```
cargo run --features fast -- --seed 42   # быстрая итерация, город по seed (без --seed — случайный) (dynamic linking, инкрементальная пересборка ~10 с)
cargo run --release           # честный FPS
cargo test -p gta_sim         # headless-гейты геймплея
```

Управление: WASD — бег, Shift — спринт, Alt — шаг, Space — прыжок, мышь — камера, Esc отпускает курсор,
ЛКМ захватывает (или стреляет, если в руках ствол). Оружие: `2` пистолет, `3` SMG, `4` дробовик, `1` кулаки/бита (повторное нажатие переключает),
ПКМ прицел, `R` перезарядка; стволы лежат в тире в центре центрального парка (рядом с самой высокой башней). Тюнинг — `assets/character/locomotion.ron`, `assets/camera/camera.ron`, `assets/world/render.ron`.

QA запущенного билда: `python tools/qa/scenarios/t1.py --out <dir>`, `t2.py`, `t3.py`, `t4.py`, `t5.py`, `t6.py`, `t7.py` (фича `dev`, BRP на порту 15702).

Бинарные ассеты (модели, текстуры, звук) в репо не
хранятся: они лежат в zip релизов рядом с exe. Для сборки из исходников папку `assets/` берём из
последнего релиза.
