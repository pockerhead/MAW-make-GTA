# PREMISE_CHALLENGE — TASK-014 (GDD T13, звук и juice)

## 1. Counter-example tested

Если часть списка цели T13 (особенно "переключатели доступности": без вспышек, меньше тряски, громкость; а также
trauma-тряска / виньетка / пульс звёзд / индикатор направления урона) УЖЕ существует в коде после T12/раньше,
то premise "реализовать T13 = построить все эти пункты" неполон: успех можно "достичь" дублированием уже
существующих конфигов/систем (второй источник одного конфига), а реальная работа слайса — подключить к
существующему, а не строить заново. Проверяю: есть ли в репо уже реализованные toggles / shake / vignette /
star pulse / damage indicator / audio.

## 3. Did it hold

Контрпример подтвердился частично и не ломает premise. Из десяти пунктов цели "переключатели доступности" в
основном сделаны T12 (громкость, тряска, вспышки; из §8 не хватает только "уменьшить движение камеры"),
выстрелы есть как заглушка, которую сам код помечает как задолженность T13, trauma-тряска есть только для
ближнего боя. Остальные семь пунктов отсутствуют. Проблема (T13 не реализован) реальна, root cause не
заявлен (это feature), цель совпадает с APPROVED GDD. Готовые части это факты для планировщика, а не
ошибка постановки: `GDD.md:360` прямо говорит, что базовые значения живут в `juice.ron`/`mix.ron`, а
настройки хранят только множители, поэтому расширение существующего, а не второй конфиг, следует из самого
закона.

Замечания к предикату успеха (не меняют вердикт, передаю планировщику):
- QA-критерий "число активных `AudioPlayer`" уже выполним существующей заглушкой выстрела
  (`src/audio/mod.rs:174-177`): он доказывает только живость звука выстрела, не сирены/эмбиент/импакты.
  Сценарию t13 стоит считать источники по классам, иначе он зелёный без новой работы.
- Гейт "juice не пишет `Time<Virtual>`" по закону gates-домена живёт в `cargo test -p gta_like` (juice в
  `src/`, прецедент `src/visuals/character_gate.rs:626`), а AC называет только `-p gta_sim`.
- Пункт §8 "уменьшить движение камеры" в список T13 (`GDD.md:645`) явно не выписан, но входит в
  "переключатели доступности" через §8.

## 4. Verdict

PREMISE HOLDS — `src/settings/mod.rs:15-28`, `src/audio/mod.rs:1,163-178` и `src/juice/shake.rs:17-28` показывают, что уже сделаны только настройки T12, выстрел-заглушка и тряска от ближнего боя, а grep по `src/`, `assets/third_party/manifest.ron` и `assets/audio/` не находит ни виньетки, ни индикатора урона, ни stinger, ни эмбиента, ни сирен, ни Kenney-звуков, ни пульса звёзд. Цель T13 (`docs/design/GDD.md:644-648`) реальна и в основном не выполнена; готовые части надо расширять, а не строить заново.
